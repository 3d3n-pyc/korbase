# korbase

An async ORM for Postgres, built the Korvex way. It is pure Python.
Models are msgspec Structs, dataclasses or TypedDicts. The driver is
asyncpg. It has SQL migrations, written for you and applied after review.

Pre-alpha: the API may change before 1.0. Python 3.10 and later.

## Install

```sh
pip install "korbase[asyncpg]"
```

## Example

This runs on a scratch database. The first statement drops the tables
`users` and `posts`.

```python
from __future__ import annotations
import asyncio
from typing import Annotated, Optional

import msgspec
from korbase import FK, PK, Database, Rel, cols, insert, select, table

DSN = "postgresql://user:password@localhost:5432/scratch"


@table("users")
class User(msgspec.Struct):
    id: Annotated[int, PK()]
    name: str


@table("posts")
class Post(msgspec.Struct):
    id: Annotated[int, PK()]
    author_id: Annotated[int, FK("users.id")]
    title: str
    author: Annotated[Optional[User], Rel("author_id")] = None


async def main() -> None:
    async with await Database.connect(DSN) as db:
        await db.execute(
            """
            DROP TABLE IF EXISTS posts; DROP TABLE IF EXISTS users;
            CREATE TABLE users (id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY, name text NOT NULL);
            CREATE TABLE posts (id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
                                author_id bigint NOT NULL REFERENCES users(id), title text NOT NULL);
            """
        )
        [ada] = await db.run(insert(User).values(name="Ada"))  # insert returns the new row
        await db.run(insert(Post).values(author_id=ada.id, title="Hello"))

        users = await db.run(select(User).where(name="Ada"))
        print(users)  # [User(id=1, name='Ada')]

        posts = await db.run(select(Post).load(cols(Post).author))
        print([(x.title, x.author.name if x.author else None) for x in posts])


asyncio.run(main())
```

## Status

Working today: models, queries, transactions, relations loaded with
`.load()`, the Korvex integration (`pip install "korbase[korvex]"`) and
SQL migrations with `python -m korbase.migrate`.

Not yet: SQLite, joins in the query builder, and the korpg driver (its
extra is empty). `.load()` raises `KorbaseError` on tables with a composite
primary key.
